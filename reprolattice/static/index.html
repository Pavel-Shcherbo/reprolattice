Replay boundaries

This workbench serves ordered HTTP/JSON fixtures on loopback. Unknown requests fail locally and are never forwarded to an upstream service. Client verification runs the bundled faulty or corrected application against the fixture. Protocol mode checks only the recorded HTTP interactions. The CLI can verify a trusted local client command.

Review fixtures before sharing. The redaction helper covers named secret fields, not every possible form of sensitive information. Application state, concurrent requests and clocks require explicit test setup.
